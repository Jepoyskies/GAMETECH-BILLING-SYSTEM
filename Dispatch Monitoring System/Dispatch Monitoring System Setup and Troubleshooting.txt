## Troubleshooting

**Unable to access the Dispatch web application:**

1. Open Command Prompt and run:
   ```
   pm2 restart dispatch-backend
   ```

2. If the problem persists, check the current IP address and use it with port **5502**:
   ```
   ipconfig
   ```
   If the issue still persists, the problem may be caused by:
   - A network connectivity issue
   - The USB Wi-Fi adapter
   - The mini PC itself
