System Updates & Changelog
August 29, 2026 — Today's improvements
✅ Payments Payment Reference Numbers & Transfer

Every payment now has a unique Reference Number (e.g., REF-20260829-0001). If a staff member accidentally activated the wrong account, you can now use Transfer Payment inside Payment Logs to move and revert the payment to the correct customer — no data is lost.

📋 Logs Payment Logs & Audit Trail Improved

Payment Logs now track who accepted the payment, the exact date & time, the amount paid, and the new running balance. Admin can filter logs per customer or by date range. All edits to customer accounts are now logged in the Audit Log for full accountability.

🔁 Sync Manager Redesigned with Suspicious User Detection

Sync Manager is completely redesigned with 3 categories:
• Active Users — on both system & router
• Mikrotik Router Users — clean users only on router (can be imported)
• Unknown/Suspicious Users — auto-detected by the system: weird characters, missing comments, or using the 'default' profile. These are potential insider threats or unauthorized PPPoE secrets.

💬 Winbox Winbox UI & Comments Improved

Winbox dashboard now loads correctly. PPPoE comments in Mikrotik are auto-formatted as Full Name | Barangay when a customer is created or updated — this makes it easy to identify customers directly in Winbox and is also used by the suspicious user detector.

💰 Staggered Payments Flexible Payment Tracking Implemented

Customers can now pay in staggered/partial amounts. For example, a ₱1,000/month plan can be paid ₱100 for 3 days, ₱500 for 15 days, etc. The system tracks the remaining balance and automatically calculates expiration based on how much was paid. A Quick Pay grid in the customer portal lets customers choose their payment amount.

🧭 Navigation Tracking & Flexibility Improved

Customer tracking is improved: connection status updates every 30 seconds automatically. Offline customers now show a smart diagnosis — it checks if the issue is isolated to that customer, a barangay-wide outage, or the entire router going offline. The router unreachable flag is also now detected automatically.

🔔 Notifications Notification Tab — Time & Date Improved

Notifications now display the exact time and date each event occurred in readable format (e.g., "Today at 10:25 AM"). High-priority alerts (like expired accounts) now pulse in red. The notification center shows unread badges and allows Mark All as Read in one click.

📺 Add-ons Cignal Box & Cignal Play Implemented

The system now supports Cignal Box and Cignal Play add-ons per customer. Staff can assign add-ons, set expiration, and track their status separately from the internet subscription. This is visible in the customer profile and can be managed from the billing section.

📊 Customers Customer List Ordering & UI Revamped

The customer list is now auto-sorted by status: Active → Pending → Suspended → Expired → Inactive → Pull Out. Expired/Suspended customers are visually highlighted in amber/gray so your staff can immediately spot who needs attention. The filter button label is also fixed (no more <= symbols!).

🔐 Security Currently Logged-In Users Monitor

The Users icon in the top bar now shows all staff members currently logged into the system in real time. This helps you quickly spot if any unauthorized person is inside the system. Only Admin-level access can see all active sessions.

🚀 All changes are live on the production server
