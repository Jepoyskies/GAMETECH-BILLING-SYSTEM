August 29, 2026 Latest Update

Payments Payment Reference Numbers & Transfer

Every payment transaction now generates a unique Reference Number (e.g., REF-20260829-0001). This enables robust auditing and tracking.

Additionally, the new Transfer Payment feature allows Admin to correct human errors. If a staff member accidentally credits a payment to the wrong customer, you can seamlessly transfer the payment record directly to the correct customer's ledger — restoring balances automatically without deleting logs.

Logs Comprehensive Payment Audit Trail

Payment Logs are now infinitely more detailed. The system tracks exactly who (which staff member) accepted the payment, the precise timestamp, the amount, and the running balance state before and after the transaction. We introduced powerful filters allowing administrators to isolate logs per customer or by specific date ranges.

Sync Manager Suspicious User Detection & Auto-Formatting

The Sync Manager was entirely redesigned with an intelligent 3-tier categorization system:

  • Active Users: Accounts present in both the Billing System and the Mikrotik router.
  • Mikrotik Router Users: Clean PPPoE profiles found on the router, ready for import.
  • Unknown/Suspicious Users: The system now automatically flags unauthorized PPPoE accounts that contain weird characters, missing comments, or exploit the 'default' profile. This acts as an automated insider-threat detection tool.

Furthermore, any changes made to customers in the billing system now automatically format their Mikrotik PPPoE Comment to Full Name | Barangay, maintaining strict organization inside Winbox.

Billing Flexible Staggered Payments System

Customers can now pay their bills flexibly in staggered or partial amounts. The system's billing engine automatically calculates the exact expiration date based on the partial amount paid (e.g., paying ₱500 on a ₱1,000/mo plan grants exactly 15 days of access). The Customer Profile UI features a new Quick Pay grid interface allowing staff to click preset payment fractions effortlessly.

Core Fixes Mikrotik Suspension Bug Resolve

Fixed a critical logic error in the synchronization engine where active customers were blocked because outdated 'Drop Rules' in the Mikrotik Bridge Filter were not being cleared upon reactivation. The system now cleanly handles the addition and removal of block rules.

August 28, 2026

Customers Customer List Ordering & UI Revamp

The Customer List layout received a major workflow upgrade. Accounts are now auto-sorted intelligently by Status:

Active → Pending → Suspended → Expired → Inactive → Pull Out

This allows staff to immediately spot accounts requiring attention. Furthermore, visual highlights (amber for expired, gray for suspended) were applied directly to table rows for instant recognition.

August 26, 2026

Deployment Live Production Deployment Architecture

This day marked the transition from local development to the live internet. We established a Production-Grade Architecture on DigitalOcean.

  • Containerized the entire application utilizing Docker and Docker Compose.
  • Set up Nginx as a reverse proxy with Gunicorn as the application server for high-performance traffic handling.
  • Implemented a seamless CI/CD pipeline via GitHub Actions allowing instant deployments whenever new features are pushed to the main branch.

August 24, 2026

Maintenance System Stabilization & Environment Tuning

A dedicated bug-squashing and stability phase. We secured environment variables (.env), optimized database queries to prevent N+1 issues on the dashboard, and patched minor routing discrepancies ahead of the major deployment phase.

August 22, 2026

UI/UX Design The Gametech Premium Redesign

We executed a system-wide visual overhaul to transform the application into an ultra-premium, modern SaaS product.

  • Integrated beautiful CSS Gradients on headers, navigation bars, and key actionable cards.
  • Rounded all container edges (border-radius: 16px) for a sleek, soft UI aesthetic.
  • Introduced Avatar Initials generating colored profile pictures for customers dynamically.
  • Added high-performance CSS micro-animations (fade-ins, subtle hover-lift effects, and pulsing badges for alerts).
  • Implemented native glassmorphism transparency (backdrop-filter: blur()) on modal backgrounds and dropdown menus.

August 20, 2026

Security Role-Based Access Control (RBAC)

Security was significantly hardened by implementing a comprehensive Role-Based Access Control matrix.

  • Administrators: Granted full destructive permissions, view of financial logs, and active session monitoring.
  • Technicians: Limited view focused strictly on Network Health, Mikrotik operations, and Sync Manager tools.
  • Customer Service Representatives (CSR): Access focused solely on viewing customer profiles, recording payments, and basic troubleshooting without the ability to delete structural records.

August 13 - 19, 2026

Customer Experience The Customer Portal

We developed a dedicated, mobile-friendly Customer Portal (/portal/). This allows end-users to:

  • Log in securely using their Account ID and PIN.
  • View their exact live connection status and router uptime.
  • Check their current expiration date, balance, and subscription plan details.
  • Generate and print their own fully-itemized Statement of Account (SOA).
Communications Automated SMS Engine

Integrated an SMS Gateway engine capable of sending automatic text messages directly to customers' phones. This engine is designed to handle automated billing reminders, expiration warnings, and bulk broadcast messages for barangay-wide maintenance announcements.

Tracking Geomapping & Dashboards

We built a live Geomap Interface utilizing OpenStreetMap technology to allow administrators to drop pins for customer NAP boxes, giving a visual representation of network density. Additionally, the first iteration of the primary Dashboard was built, tracking daily revenue charts, active user counts, and system alerts.

August 11 - 12, 2026

Genesis Legacy Migration to Python/Django

The project began with a massive overhaul: abandoning the old, insecure, hard-to-maintain legacy PHP codebase. We initialized a completely modern, robust Python/Django framework.

This involved migrating all the legacy MySQL tables into the new Django ORM, ensuring that not a single customer record, plan, or payment history was lost during the transition.

Infrastructure Direct Mikrotik RouterOS Integration

We successfully established a 2-way live connection between the Django web server and the Gametech Mikrotik Router (192.168.88.2) using the official RouterOS API. This was the most critical breakthrough of the project, allowing us to do the following autonomously:

  • Automated Activations: Creating a customer in the Billing System now instantly creates their PPPoE Secret inside the Mikrotik router. No more manual Winbox entry!
  • Live Connection Status: The dashboard now reads the Mikrotik's Active Connections list in real-time, accurately displaying exactly who is currently online, their IP address, and their session uptime.
  • Automated Terminations: If an account is deleted or suspended in the billing system, their PPPoE session is instantly kicked (disconnected) from the router.
Core Logic The Expiration & Suspension Engine

We engineered the foundation of the automated billing cycle. The system was programmed to track exact date/time expirations for every subscription plan. We built the logic to automatically flag accounts as Expired once their due date passes, and established the backend hooks to execute suspension commands directly to the router to block internet access without human intervention.
